# How to reset Wi-Fi on a Brother HL-L2350DW and reconnect it

If you changed your router or Wi-Fi password, you can enter the new details directly in the printer’s **Setup Wizard**. To clear the old network configuration altogether, choose **Network Reset** on the HL-L2350DW, let it restart, and then run the wizard.

## What a network reset erases

Have the Wi-Fi name and password ready before resetting. Brother says the reset also clears print-server settings such as its password and IP address. If you simply want to join a different router, go straight to the [Setup Wizard](#join-the-wi-fi-network). ## Clear the saved network settings

1. At the printer, use the arrow keys to find **Network**. Press **OK**.
2. Scroll to **Network Reset** and press **OK**.
3. Choose **Yes** and wait for the printer to restart. [Brother HL-L2350DW network reset](https://support.brother.com/g/s/id/htmldoc/printer/cv_hll2310d/use/html/GUID-AD10E66A-D2ED-4BDB-8C52-550C32029372_61.html)

## Join the Wi-Fi network

1. Open **Network**, then **WLAN (Wi-Fi)** and **Setup Wizard**. Press **OK** at each selection.
2. If the screen asks **WLAN Enable?**, choose **On**. The printer scans for nearby network names.
3. Select your network name (SSID) and press **OK**. For a password-protected network, enter its Wi-Fi password, then confirm and apply the settings.
4. Wait for **Connected** on the printer’s display. That confirms the printer joined the selected network. [Brother’s HL-L2350DW setup wizard](https://support.brother.com/g/s/id/htmldoc/printer/cv_hll2310d/use/html/GUID-6724461D-8AB1-4461-B32B-CA39AE21FD9A_45.html)

## If the connection fails

Print the wireless status report to see what the printer recorded. From the printer’s menu, select **Print Reports** and press **OK**, select **WLAN Report** and press **OK**, then press **Go**. The sheet gives an error code when a connection attempt has failed. Use that code when checking the settings or asking for support.
