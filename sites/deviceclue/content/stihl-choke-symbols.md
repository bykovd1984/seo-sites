## Which STIHL choke symbol means on or off?

On the documented STIHL 017 and 018 chainsaws, **cold start closes the choke shutter**; warm start opens it. After the cold engine first fires, move the Master Control lever to warm start before continuing. Once the engine runs, the control returns to its normal run position when the throttle is activated. These are positions for those saws, not a universal symbol chart for every STIHL product.

The word “off” can mean either **choke off** or **engine stop**. Those are different actions. An open choke lets the warmed engine run normally; STOP shuts the engine down. Match the complete symbol and model before moving the lever.

## Cold start, warm start, run and stop

For the 017/018 Master Control described by STIHL:

| Position | What it means |
| --- | --- |
| Cold start | Choke shutter closed; starting throttle is set for a cold engine. |
| Warm start | Choke shutter open; starting throttle remains set for starting. |
| Run | Normal running position after the engine starts. |
| Stop | Ignition is interrupted to stop the engine. |

The manufacturer shows distinct pictograms on the machine. If a symbol has worn away, compare the layout with the diagram for the exact saw rather than deciding from lever direction alone. Other STIHL machines use different controls, and some M-Tronic chainsaws use a single start position instead of this cold/warm sequence.

## When should the choke be opened?

For the 017/018 example, use cold start for a cold engine. As soon as it begins to fire, move the lever to warm start and continue the manufacturer’s starting sequence. A warm engine starts in the warm-start position; STIHL also specifies that position if the engine has already run but is still cold. Leaving the lever on cold start can flood the engine.

Do not force the lever into a position. Follow the saw-specific instructions for engaging the control and returning it to run. “Warm start” is a starting setting, not an instruction to leave a running saw at starting throttle.

## Before starting

Follow the full safety instructions for your saw, wear the specified protective equipment and keep other people clear. STIHL’s starting guidance calls for engaging the chain brake and ensuring that the bar and chain are clear of obstructions. Never start a fuel-burning engine in an enclosed space. If the controls, starting system or markings do not match the example above, identify the exact model first.

If you are comparing an unfamiliar machine rather than a STIHL saw, our [general guide to choke positions](/guides/choke-symbols-on-off) explains why a closed choke and an open choke should not be confused with engine stop.
