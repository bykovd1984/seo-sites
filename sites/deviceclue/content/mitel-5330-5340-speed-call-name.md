# How to change a saved speed-call name on a Mitel 5330 or 5340

If the old name appears beside a speed-call button and your phone offers **Edit Label**, you can rename that button in **Settings**. For example, when Reception becomes Front Desk but keeps the same extension, you only need to edit the lettering. If the name appears inside the **People** list on a 5340, open the [contact’s name in People](#if-the-saved-name-is-in-people-on-a-5340). [Mitel’s 5330/5340 key-label instructions, hosted by SaskTel](https://www.sasktel.com/attachments/support/mitel-5330-5340-userguide.pdf#page=17) · [Mitel’s 5340 People instructions](https://www.mitel.com/sites/default/files/s3_imports/Devices%20and%20Accessories/IP%20Phones/5300%20Series/5300%20IP%20Phones%20Platform%20Specific%20Documents/MiVoice%20Business/6.0/en/MCD_5330-5340_UG_R6.0_EN.pdf#page=32)

## Rename the button when Edit Label is available

1. Open **Settings** and choose **Programmable Keys**.
2. Press the button whose existing name you want to change. Select **Edit Label**.
3. Use **Backspace** to remove the old lettering. Enter the new name on the screen keyboard. The page-navigation keys reveal more letters.
4. Press **Save**, then **Close**. Check the label beside the button on the phone screen. [Mitel’s original guide, Edit Key Labels](https://www.sasktel.com/attachments/support/mitel-5330-5340-userguide.pdf#page=17)

## If your phone offers Edit Info

Mitel’s Communications Director 6.0 guide uses **Edit Info** for a new speed-call label and **Edit Number** for its destination.

## Before clearing an occupied key

The Communications Director 6.0 procedure for reusing an occupied key starts by clearing that key. Have the full number or extension available before replacing a working shortcut. If you have a spare programmable key, you can set up the new label there and keep the existing shortcut available while you check it. [Mitel’s Communications Director 6.0 speed-call procedure](https://www.mitel.com/sites/default/files/s3_imports/Devices%20and%20Accessories/IP%20Phones/5300%20Series/5300%20IP%20Phones%20Platform%20Specific%20Documents/MiVoice%20Business/6.0/en/MCD_5330-5340_UG_R6.0_EN.pdf#page=30)

## If the saved name is in People on a 5340

On the Communications Director 6.0 system, open **People**, select the contact, and press **Edit Name**. Make the correction and press **Save**. The contact’s number has its own edit field. The guide assigns this People-list procedure to the **5340**.
