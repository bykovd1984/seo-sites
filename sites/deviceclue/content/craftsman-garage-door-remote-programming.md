## How do you program a Craftsman garage door remote?

First identify the **full opener model and remote model** and confirm that they are compatible. Many Craftsman systems use a LEARN button, but the steps and compatible accessories vary. Programming one remote is a different action from erasing all stored controls.

The example below is for Craftsman **139.54915**, using its opener-mounted LEARN button and a compatible remote. A label such as “1/2 HP” describes motor power and is not enough to identify the programming procedure. Keep people, pets and objects clear of the door throughout programming and testing.

## Example: add a remote to model 139.54915

The manufacturer’s instructions describe this sequence for the documented opener:

1. Locate the opener’s LEARN button and indicator. Use a stable ladder if necessary; do not reach across moving parts.
2. **Press and release** LEARN. The indicator stays on for 30 seconds.
3. Within those 30 seconds, press and hold the button on the compatible remote that should operate the door.
4. Release the remote button when the opener light blinks. If no light bulbs are installed, the guide says two clicks are the confirmation.
5. Test the remote with the door visible and its path clear.

That is the procedure for the specified model and method. The same guide also describes programming through a particular wall control. A different opener or remote may use another sequence; follow the instructions for both pieces of equipment.

**Do not hold the opener’s LEARN button while trying to add a remote.** On this model, holding it until the indicator goes out erases stored remote and keyless-entry codes. If you deliberately need to remove a lost remote, see [how to reset a Craftsman garage door opener](/guides/craftsman-garage-door-opener-reset) first.

## What if the opener does not learn the remote?

| Check | What it helps establish |
|---|---|
| Full model numbers and accessory compatibility | A remote can look similar without supporting the opener’s system. |
| Remote battery | A weak battery may stop the remote transmitting reliably. Install the specified replacement correctly. |
| Programming window and confirmation | On the example model, begin the remote step within 30 seconds and look for the documented signal. |
| Wall control and another working remote | These help distinguish a single remote problem from a wider control or opener problem. |
| Wall-control lock | On supported controls, the lock feature can prevent remote operation while the wall button still works. |

If the light flashes but the door will not close, do not assume the remote is the cause or bypass safety sensors. Our [Craftsman troubleshooting guide](/guides/craftsman-garage-door-troubleshooting) covers symptoms and documented diagnostic clues.

## Will a new remote erase the old one?

Adding a remote is not the same instruction as the full memory erase on the documented 139.54915. Do not assume that a missing or stolen remote has been removed simply because you added a replacement. Consult the model-specific erase procedure if access must be revoked, and plan to reprogram the controls you still need.

## How do I program a keypad instead?

A keypad uses a PIN and may have its own setup sequence in addition to the opener instructions. See [programming a Craftsman garage door keypad](/guides/craftsman-garage-door-keypad-programming) for a model-specific example. Never share your PIN in a public support request.

If the remote battery is weak, see our [Craftsman remote battery replacement guide](/guides/craftsman-garage-remote-battery) before attempting to reprogram it.
