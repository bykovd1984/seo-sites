## Match the programmer before using the steps

Smeg has used different timer and clock layouts. A three-button programmer, an analogue clock, and a touchscreen should not share an assumed button sequence. Photograph the controls and find the appliance model first.

The worked example here comes from section 3.10 of an official Smeg-hosted document. Its programmer has a decrease button, a clock button and an increase button. Verify that both the controls and the instructions match your appliance. This is a documented panel example, not a verified list of every model that uses it.

## Initial setting on the documented three-button panel

For the initial setting described on printed page 34:

- Hold the clock button for two seconds, until the separator between hours and minutes flashes.
- Use the increase and decrease buttons to set the displayed time.
- Leave the buttons alone for seven seconds, until the separator stops flashing.

This sequence is for the documented programmer after first use or a power interruption. Follow the complete source if the display shows an additional symbol or a different state. Do not treat the time-of-day setting as a cooking-duration control.

## Changing a time that is already set

The same document describes a different entry step for changing an existing time: hold the increase and decrease buttons together for two seconds, then adjust the time.

That difference matters when changing the clock seasonally. Holding the clock button repeatedly can lead you into a timer function on some programmers. Read the paragraph for the task you are doing, not just the first paragraph that mentions a clock.

## After a power interruption

A flashing display after power returns can mean the time needs setting again. The example programmer requires the time to be set before the oven can switch on. That is a statement about the linked system, not every Smeg appliance.

Before investigating a heating fault, check whether the clock is steady and whether a timed-cooking function is still selected. Identify any symbol using the same model document. An unfamiliar symbol is a reason to check the guide, not to try random combinations.

## Keep the clock and cooking timer separate

| Task | The question to ask |
|---|---|
| Set the time after installation | Which initial clock-setting procedure applies? |
| Correct a saved time | How does this programmer enter time-edit mode? |
| Count down a few minutes | Is the minute minder selected? |
| End cooking automatically | Is a cooking-duration or programmed-cooking function involved? |

If the source’s sequence does not produce its described display, stop and verify the model and programmer. Do not remove the panel or expose wiring for a clock adjustment. Smeg’s support route can help identify the right instructions for a nonmatching control.
