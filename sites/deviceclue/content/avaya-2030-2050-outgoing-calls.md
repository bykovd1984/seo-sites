# How to make an outgoing call on an Avaya 2030 or 2050 desk phone

On an **Avaya 2030 or 2050 connected to IP Office**, dial a colleague’s extension for an internal call. To call outside the office, dial the full telephone number. Add an outside-line prefix only if your telephone administrator has set one for your office. You can dial with the handset resting on the phone, listen for ringing, then pick up when the other person answers. [Avaya’s IP Office 2030 and 2050 guide, pages 4–6, archived copy](https://device.report/m/84f7df825d5df55f21a52b55b8c6e1b42cb94f197d704570f0f70732a93ebd8c.pdf#page=4)

## Call an outside number

1. Start with the phone idle. If your office gives staff an outside-line digit, enter it first. Otherwise start with the number you want to call.
2. Dial the number in the format your office uses for that destination. Watch the display as the call goes through.
3. Use the handset or continue hands-free when someone answers. To end the call, replace the handset or press **Answer Release** when working hands-free. [Avaya’s 2030 and 2050 instructions for outgoing calls, archived copy](https://www.manualsdir.com/manuals/42780/avaya-2050-2030.html?page=10)

**Do you need to dial 9 first?** Only if 9 is the outside-line prefix at your workplace. IP Office lets the telephone administrator configure the prefix. If another extension in the office can call the same destination, ask what format its user dialled. [Avaya’s explanation of outside-line prefixes](https://documentation.avaya.com/en-us/home/bundle/ip-office/ipofficewebmanagerr12_3/general-system-configuration/caller-display.html)

## If the display asks for an account code

An **Account** prompt means that the office system requires a code for the call. Use the account code your office assigned for that purpose. Where the display prompts for entry, type the code and select **Done**. If **Reenter Account** appears, check the assigned code with the person who manages your phone system. A destination number and an account code go in different prompts. [Avaya’s account-code instructions, page 8, archived copy](https://device.report/m/84f7df825d5df55f21a52b55b8c6e1b42cb94f197d704570f0f70732a93ebd8c.pdf#page=8)

## If an extension works but an outside call fails

Try a colleague’s extension first. A successful internal call tells you that the handset can reach another extension. If outside calls still fail, note the destination type, the prefix used, the display message and the time. IP Office can restrict which external numbers an extension may call. Those details let your administrator distinguish a dialling-format problem from a restriction. [Avaya’s 2030 and 2050 guide, Making External Calls](https://www.manualsdir.com/manuals/42780/avaya-2050-2030.html?page=10)

## Redial a recent outside number

To repeat a previously successful outside call on the layout in Avaya’s guide, press **Redial** until the intended number appears, then select **Call** beside the display. Confirm the number before placing the call, particularly on a shared desk phone. [Avaya’s redial instructions, page 6, archived copy](https://device.report/m/84f7df825d5df55f21a52b55b8c6e1b42cb94f197d704570f0f70732a93ebd8c.pdf#page=6)

If outgoing calls work but your own extension does not ring for incoming calls, check [Do Not Disturb on Avaya IP Office](/guides/avaya-phone-do-not-disturb).
