# Samsung POWERbot C03 and C05 errors: wheel and bumper checks

In Samsung's cited POWERbot code table, **C03 points to material caught at the right drive wheel; C05 calls for a bumper-sensor check**. Check the complete model before using that interpretation, because Samsung warns that codes can differ between models. A displayed code is a starting point for inspection, not a diagnosis of a failed motor or sensor.

Read and photograph the exact characters first. If there is no code and the problem is receiving charge, start with [POWERbot charging checks](/guides/samsung-powerbot-not-charging) instead.

## C03 and the right drive wheel

Switch off the emergency switch before touching the wheel. Inspect for accessible hair, thread or other debris and remove it gently without dismantling the wheel module. Do not force a jammed mechanism or insert a tool into the housing.

[Samsung's C03 explanation](https://www.samsung.com/za/support/home-appliances/check-the-information-codes-on-my-powerbot/) identifies the right driving wheel, while C02 refers to the left wheel in that same table. Match the side to the robot's normal forward direction; do not choose a side solely from how the upside-down robot faces you.

## C05 and the bumper

For C05, Samsung first describes switching the emergency switch off and back on. If the warning remains, inspect the gap between the bumper and the body for foreign material. Switch off before removing an obstruction, and avoid forcing the bumper or opening the sensor assembly.

If the bumper is visibly damaged or the code immediately returns despite a clear gap, stop and request service. Repeated resets will not identify an internal failure.

## Clean sensors without covering them

[Samsung's maintenance instructions](https://www.samsung.com/sg/support/home-appliances/how-to-clean-and-maintain-samsung-powerbot-robot/) specify gentle wiping with a soft cloth for the sensors and camera, without water or cleaning solutions. The same page's wheel-cleaning procedure turns the emergency switch off before debris removal.

Use the model's diagram to identify each sensor surface. Keep liquid out of the robot and do not cover cliff sensors with tape to suppress a warning. Those sensors serve a protective function; a warning disappearing after they are covered does not establish that the robot is safe to use.

## Nearby codes are not interchangeable

The cited code table also gives these examples:

| Code | Area identified in that table |
| --- | --- |
| C01 | Brush obstruction |
| C02 | Left drive-wheel obstruction |
| C06 | Obstacle-sensor contamination |
| C07 | Cliff-sensor contamination |
| C11 | Main control-board inspection |

For C11 or an unfamiliar code, use model-specific support rather than opening the electronics. Do not interpret a missing code from this short table as a harmless condition.

## Retest and record what returns

After accessible cleaning is complete and the robot is reassembled, restore the normal operating switch position and observe a short run in a clear area. Note whether the same code returns immediately, after a turn or at a particular obstacle. Keep away from the moving wheels and brush.

Send support the model number, exact code, any visible damage and the checks already completed. If the robot remains stuck or a warning returns, stop troubleshooting before a simple debris check becomes an unsupported internal repair.
