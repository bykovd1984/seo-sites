# What Audyssey DSX does on a Denon AVR-X4100W

**Audyssey DSX** stands for **Dynamic Surround Expansion**. On the **Denon AVR-X4100W**, it takes a surround mix such as 5.1 and creates additional signals for a pair of front wide or front height speakers. The extra speakers determine where you hear the effect. If your aim is to correct how the room sounds through the speakers you already have, **MultEQ XT32** handles that job using measurements from the setup microphone. [Denon’s guide to Audyssey processing](https://manuals.denon.com/avrx4100w/NA/EN/WBSPSYezcafzyn.php)

## Which speakers does DSX use?

| Your speaker layout | What to select on the AVR-X4100W |
| --- | --- |
| A front wide pair outside the main left and right speakers | **Wide** directs the extra channels to the sides of the front soundstage. |
| A front height pair above the main left and right speakers | **Height** directs the extra channels above the front pair. Denon places these speakers near the ceiling, aimed at the main seat. |
| Both front pairs in a supported configuration | **Wides/Heights** uses both pairs. |

The receiver also needs a center speaker. A 7.1 layout whose extra pair sits behind the couch has surround back speakers. For DSX, look for the positions Denon labels **FWL/FWR** or **FHL/FHR** in its diagram. [Denon’s speaker placement diagrams](https://manuals.denon.com/AVRX4100W/NA/EN/WBSPSYsfbtssfo.php) · [Denon’s DSX settings](https://manuals.denon.com/AVRX4100W/NA/EN/GFNFSYphwaueoj.php)

## How to turn it on and compare it

Select the input you use for movies, then open **Setup → Audio → Audyssey → Audyssey DSX** and choose the installed pair. The factory setting is **Off**. Replay the same short scene with DSX on and off. If you want to change how far the sound appears to spread, **Stage Width** and **Stage Height** each run from **−10 to +10**, with **0** as the starting point. Denon remembers the DSX setting for each input. [Denon’s menu map](https://manuals.denon.com/avrx4100w/na/en/GFNFSYghukzrll.php) · [Denon’s adjustments and defaults](https://manuals.denon.com/AVRX4100W/NA/EN/GFNFSYphwaueoj.php)

## Why is DSX unavailable with this source?

The AVR-X4100W cannot apply DSX to a **two-channel input signal**. If the setting is unavailable during a movie, open **Setup → General → Information → Audio** and look at **Format**. It shows the incoming channel count. If it shows only the two front channels, select a multichannel soundtrack on the player and check the display again. [Denon’s input signal display](https://manuals.denon.com/AVRX4100W/NA/EN/GFNFSYcsmwwkkn.php) · [Denon’s source requirements](https://manuals.denon.com/AVRX4100W/NA/EN/GFNFSYphwaueoj.php)

## What if the soundtrack already has wide and height channels?

If an HD audio signal already contains both front height and front wide channels, the AVR-X4100W plays those channels directly from the recording. The DSX control is unavailable for that signal, even with the correct speakers connected. [Denon’s AVR-X4100W Audyssey settings](https://manuals.denon.com/AVRX4100W/NA/EN/GFNFSYphwaueoj.php)
