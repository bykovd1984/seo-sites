# VTech phone ringer volume: turn the ring up, down or on

To make a VTech phone ring louder, adjust **ringer volume while the handset is idle**. The volume you change during a conversation controls the voice you hear. Some systems also have a separate base ringer and Quiet mode, so a loud handset setting does not necessarily make every part of the system ring.

Find the model number on the handset or base before following a button sequence. DECT 6.0 describes the telephone technology; it does not identify a particular menu. The examples below cover the I6765 and CS5129 families.

## I6765 handset volume

On the I6765, start with no call in progress:

1. Press MENU/SEL and use the arrow keys to find RINGER VOLUME.
2. Press MENU/SEL to open the setting.
3. Use the arrows, or a number from 0 to 6, to choose a level. Listen to the sample.
4. Press MENU/SEL to save it.

The lowest setting silences incoming calls. Choose a higher level to turn the ringer back on. [VTech's I6765 support page](https://www.vtechphones.com/support/technical-support/product/569) also describes an idle-handset shortcut using the side volume keys; do not assume that shortcut works on another model.

## CS5129 handset and base settings

For a CS5129-family handset, press MENU while idle, find Ringers with the arrows, then press SELECT twice to reach the volume choices. Choose a level and press SELECT to save. On the base, use its volume controls while the phone is not in use; zero turns that base ringer off.

The [CS5129 instructions](https://cdn-media.vtechphones.com/media/p/document2/products/%7BF2FE0709-18C0-4F92-9257-E93C1F032BE5%7D/CS5129-X_WEBCIB_V2_20160215.pdf) distinguish these controls from Quiet mode. If Quiet mode is displayed, hold the handset's QUIET# key while idle to turn it off. Ringer samples can still sound while Quiet mode is active, so a sample alone does not confirm that the next call will ring.

## Check which sound is missing

| What you want to change | Setting to check |
| --- | --- |
| Incoming calls are too quiet | Handset ringer volume |
| Handset rings but the base is silent | Separate base ringer, if fitted |
| Caller's voice is too quiet | Listening volume during a call |
| Calls are silent during a quiet period | Quiet mode, if available |

Change one setting at a time. It is easier to identify the cause when you can compare the result before and after a single adjustment.

## Test with an incoming call

Return the handset to its normal idle screen and call the home number from another phone. Check the handset and base separately. If you have several handsets, note which ones ring rather than judging the whole system by the nearest unit.

On the CS5129, FIND HANDSET can produce a paging tone even with the incoming ringer disabled. Use an actual incoming call for the final check.

## If it still does not ring

Record whether the incoming call appears on the display, whether another handset rings and whether you can answer. That gives support a clearer symptom than “the volume is broken.” A connection message, missing incoming call or persistent failure after the correct setting needs model-specific troubleshooting; repeatedly increasing listening volume will not test the ringer.
