## Read the complete symbol

A fan, a fan inside a circle, and a fan with a heating line are not necessarily the same function. Start by noting every part of the marking: the outside box, the fan, any surrounding ring, and any line at the top or bottom.

Beko’s general overview gives useful clues, but its model-support advice points to the individual oven’s function table. Use the common meanings below to orient yourself, then confirm the exact mode before cooking.

## Common visual clues

| Marking described | Common meaning in Beko’s overview | What to verify on your model |
|---|---|---|
| Two straight lines, top and bottom | Conventional upper-and-lower heating | Which elements are active and the recommended shelf position |
| Fan or fan in a circle | A fan-related cooking mode | Whether the fan has a dedicated heating element |
| Jagged line at the top | Grill | Whether it is a full-width, part-width or combined mode |
| A defrost marking | A defrost function | The actual symbol and whether the mode uses heat |

These are descriptions, not a photographic identification chart. The artwork on this page is conceptual and does not establish the controls of a particular Beko model.

## Fan cooking versus fan-assisted functions

The important question is not simply whether a fan is pictured. Ask what else is drawn with it. A grill line combined with a fan points to a different cooking function from a plain fan-related setting.

If the appliance is an AEG, use the separate [AEG oven symbols guide](/guides/aeg-oven-symbols) for its grill and fan examples. Do not choose a mode solely because another oven had a similar symbol. Put a photo of your own dial beside the correct model’s function table and compare the complete shapes. If the printed marking is worn away, the knob position by itself is not a reliable identification.

## What about an older oven?

Age does not provide a single replacement legend for missing symbols. Find the model on the data plate and locate that model’s function information through Beko support. A clear photo of the panel can help identify the question, but it should be used alongside the model number.

If the symbols are unreadable, avoid testing unknown heating modes to work out what each position does. Ask support for the correct panel or function information instead.

## Before selecting a cooking mode

- Identify the oven model rather than relying on the brand alone.
- Compare the entire marking, including the lines around the fan.
- Check the source’s shelf, accessory and temperature advice for the selected function.
- Keep a minute-minder symbol separate from a cooking-function symbol.

A flashing time display calls for a clock-setting procedure rather than a different cooking mode. If the appliance you are checking is a Smeg or Zanussi, use the separate guide to [setting a Smeg oven clock](/guides/smeg-oven-clock) or [setting a Zanussi oven clock](/guides/zanussi-oven-clock). Those brand-specific button sequences are not instructions for a Beko programmer.

If a correctly identified function does not behave as the model documentation describes, treat that as a separate operating question. A symbol guide explains the intended setting; it cannot confirm that the appliance’s elements, fan or thermostat are working.

For a different appliance, see the separate guides to [Bertazzoni oven functions](/guides/bertazzoni-oven-symbols) and [Zanussi oven symbols](/guides/zanussi-oven-symbols). Their function charts must be matched to the actual brand and model.
