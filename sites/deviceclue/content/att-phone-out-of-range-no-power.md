# AT&T phone says out of range or no power at base

An AT&T cordless handset displaying **Out of range OR No power at base** cannot establish its normal link with the telephone base. Start by checking the base's power and bringing the handset close to it. The message does not, by itself, prove that the battery or telephone line has failed.

Identify the main base before troubleshooting. An extra charging cradle is not necessarily the base that communicates with the handsets. Keep the model numbers of both the handset and base available, especially if they came from different sets.

## Check power and distance first

Check that the correct AT&T power adapter is firmly connected to the main base and a working outlet. Make sure a wall switch has not turned that outlet off. Move the handset beside the base, then return it to the cradle briefly and try again.

[AT&T's TL86109 troubleshooting guidance](https://telephones.att.com/product-support/faqs/symptom/378/353) also recommends separating the telephone from nearby electronic equipment and trying a better base location. Test in the same nearby position after each change. A handset that works beside the base but loses its link in another room gives you a different starting point from one that never connects.

## Compare the other handsets

If the set has multiple handsets, write down what each one shows:

| Observation | Useful next check |
| --- | --- |
| All handsets show the message | Main base power and the shared setup |
| Only one handset shows it beside the base | That handset's battery connection and registration status |
| It happens only in one room | Placement, distance and nearby interference |
| Display says Not Registered | Registration instructions for that exact set |

These comparisons help narrow the investigation; none identifies a failed component on its own. Do not buy a replacement base solely because the message includes the words “no power.”

## Restart a matching system

For the TL86109 example, AT&T describes disconnecting base power and the removable handset batteries, waiting a few minutes, then reconnecting base power followed by the batteries. Allow about a minute for the link to return. The clock may need setting afterward.

Use your model's restart instructions if they differ. Do this when nobody needs the phone: calls cannot be made through a disconnected base. Stop if a battery is swollen, leaking or damaged, or if the power equipment is unsafe to handle.

## Registration is a separate step

Do not deregister every handset as a first response. AT&T provides [separate registration guidance for the DLP73210 family](https://telephones.att.com/product-support/faqs/symptom/4375/446), illustrating why instructions must match the set. That example uses a charged compatible handset placed on the base; other families can use a different procedure.

If you recently replaced a base or added a handset, check compatibility and registration against both model numbers before proceeding.

## When to contact support

After power, proximity and the correct restart have been checked, give support the exact message, model numbers and results for each handset. If the link returns but there is still no dial tone, describe that separately. Restoring the handset-to-base connection and restoring telephone service are different troubleshooting outcomes.
