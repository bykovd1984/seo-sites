## Why is my Craftsman garage door remote not working?

First try the wall control and, if available, another already-paired remote. If the wall button opens and closes the door but one remote does not, check the remote's battery, compatibility, lock mode and programming. If neither the wall control nor the remote operates the opener, start with the opener and door rather than assuming the handset is faulty.

Keep people, pets and objects clear of the door during every test. These checks use examples documented by Chamberlain Group; Craftsman products span different generations, so match any control sequence and replacement part to your particular opener and remote.

## Is the problem the remote or the opener?

| Observation | Useful next check |
| --- | --- |
| Wall control works; one remote fails | Try its correct battery, then compare it with another paired remote. |
| Wall control works; no remotes work | Check the wall control's lock or vacation feature if equipped; interference or lost pairing are also possible. |
| Remote works only very close | A weak battery or radio interference can reduce range. |
| Neither the wall control nor the remote works | Check the accessible power supply and look for a diagnostic indication. A door or opener fault may need service. |
| New remote has never worked | Confirm the exact remote is compatible with the opener before trying to pair it. |

These observations narrow the problem; they do not identify a failed receiver or circuit board on their own. If the opener responds but the door reverses or the light flashes, use the [general troubleshooting guide](/guides/craftsman-garage-door-troubleshooting) and identify the model's signal.

## Check the battery and lock mode

Some wall controls have a lock feature that ignores remote commands while the wall button continues to work. Check your own wall control's labels and instructions. The indicator and method to turn the feature off vary; do not assume every Craftsman has one.

Install the battery specified for your handset, observing polarity and the condition of its contacts. Button batteries are dangerous if swallowed: keep them away from children and secure the cover. Our [Craftsman remote battery guide](/guides/craftsman-garage-remote-battery) explains how to identify the correct battery without assuming all remotes use the same type.

## The remote works only from nearby

Test from a safe position close to the opener, then from your usual operating position. If a fresh correct battery helps only briefly or several remotes have poor range, nearby electrical equipment or building materials can affect the radio signal. Chamberlain Group identifies some LED bulbs as a possible source of interference on compatible systems. Do not disconnect wiring or alter an antenna as a first step; use the manufacturer's instructions or ask a technician.

## Does the remote need to be programmed again?

It may, especially if it is new, has been removed from memory or the opener's memory was cleared. Follow the matching [remote programming guide](/guides/craftsman-garage-door-remote-programming). Holding a learn button can erase other paired accessories on some systems; it is not a harmless general reset. Identify the opener and remote before pressing it.

## When should I call for help?

Stop using the opener and arrange qualified service if the door moves unexpectedly, binds, reverses unpredictably or has damaged springs or cables. Do not adjust springs or bypass safety sensors. If the wall control and all remotes fail despite an accessible power check, record the model and any flashing pattern for the service technician.
