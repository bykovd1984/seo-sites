# How to set the clock on a Frigidaire Gallery FGET3065PF oven

On the **Frigidaire Gallery FGET3065PF** double wall oven, use the dedicated **Set Clock** key and number pad. After a power interruption, the display can flash and the oven requires the time of day before it will operate. You can set the clock without starting either oven.

## Enter the time and clear CLO

1. Tap **Set Clock** once. The display shows **CLO**.
2. Type the time on the number pad. For 1:30, press **1**, **3**, **0**. It is normal for the CLO prompt to stay on while you enter the digits.
3. Press **Start** to save. CLO disappears and the clock begins running.

If you reached a screen marked **12Hr dAY** or **24Hr dAY**, you held the key long enough to open a different setting. Press **Off** to leave that choice, then use a short press of Set Clock to enter the time. [Frigidaire’s control instructions, printed page 9](https://frigidaire.bynder.com/m/6b871c8c77870ad0/original/139900302en-pdf.pdf#page=9)

## Change between the 12-hour and 24-hour display

The factory setting for this panel is 12-hour time. To change it, hold **Set Clock** for about six seconds, until the control beeps and shows the format. While that format is displayed, use **Self Clean** to toggle between **12Hr dAY** and **24Hr dAY**. In this menu the key selects a clock format. Press **Start** to confirm or **Off** to discard.

After confirming, set the current time again using the three steps above. In 24-hour mode, 1:30 in the afternoon is **13:30**. This is an easy check if the digits look plausible but a delayed start is scheduled for the wrong part of the day.

## Which time control do you need?

| What you want to do | Key on the FGET3065PF panel |
| --- | --- |
| Correct the time after an outage or daylight-saving change | Set Clock |
| Run a countdown while working in the kitchen | Timer On-Off |
| Set the cooking duration for a timed bake | Bake Time |
| Choose a later starting time for a cooking program | Delay Start |

The kitchen timer can run independently of cooking. Entering the current time into the timer field would start a countdown and leave the oven clock unchanged.

## If your Frigidaire panel has different keys

Check the model label before trying a different sequence. Some Frigidaire appliances have arrow keys or an on-screen settings menu. For this guide the model is **FGET3065PF**, and the illustrated Gallery keypad is on printed page 8. If yours matches but does not accept the entry, note the characters still displayed and whether the keypad responded to Start. Those details help when contacting [Frigidaire model support](https://www.frigidaire.ca/Owner-Centre/Product-Support/FGET3065PF).
