# SEO sites

Репозиторий самостоятельных статейных сайтов. **Równa ściana**: десять польских статей о подготовке стен и дефектах окраски. **DeviceClue**: десять англоязычных ответов о технике, настройках, обозначениях и ошибках.

## DeviceClue

Сайт: [sites/deviceclue](sites/deviceclue), домен — **https://deviceclue.site**. DNS и публичный деплой разрешены владельцем 01.11.2026. Код использует тот же стек Node 24 / Next.js / SQLite, но самостоятельное оформление и контент. Независимая техническая экспертиза статей ещё не выполнена.

Автодеплой: `.github/workflows/deploy-deviceclue.yml`, runner `seo-sites` на том же VPS. Контейнер `seo-deviceclue`, адрес `127.0.0.1:5006`, каталог `/opt/seo-sites/deviceclue`. Скрипт проверяет отдельный кандидат, точный SHA в health и все страницы; при сбое возвращает предыдущий образ и Compose. Caddy импортирует `/etc/caddy/domains/deviceclue.caddy`. `www` перенаправляется на основной домен; TLS обслуживается Caddy.

В Namecheap BasicDNS: A `@` → `65.108.142.86`, CNAME `www` → `deviceclue.site.`. Почтовая конфигурация сохранена. Публичные страницы разрешены для индексации; поиск и API исключены. Sitemap содержит 18 URL. GSC/Bing и аналитика для DeviceClue не настроены в рамках этого деплоя.

Workflow польского сайта ограничен его файлами, поэтому DeviceClue-only изменения не перезапускают Równa ściana. Изменения только конфигурации workflow можно проверить ручным `workflow_dispatch`. Секреты, локальные исследовательские файлы, базы и скриншоты проверки не добавляются в Git.

Код, оформление, статьи и изображения: [sites/rowna-sciana](sites/rowna-sciana). Тексты перенесены без изменений; [контрольные суммы](migration-articles.json). Даты проверки источников и статус редакционных черновиков сохранены.

## Локальный запуск

Node.js 24 LTS:

```powershell
cd sites/rowna-sciana
npm ci
npm run db:seed
npm run dev
```

Адрес разработки: http://127.0.0.1:3000. Для production: `npm run build`, затем `npm start`.
Проверки: `npm test`, `npm run typecheck`; HTTP smoke: `npm run smoke` при работающем сервере.

## Автоматический деплой

Push в `main` запускает [.github/workflows/deploy.yml](.github/workflows/deploy.yml). PR проверяются на GitHub-hosted runner; production job работает только из main этого репозитория на отдельном runner `seo-sites` того же VPS, где размещены Grammar Guru и Grammar Flashcards.

Docker собирает Next.js standalone и собственную SQLite `/app/data/content.sqlite` из Markdown. Runtime открывает её только для чтения. Данные пользователей отсутствуют, поэтому внешняя общая PostgreSQL не требуется. Каждый образ содержит согласованные код и контент; изменение статей применяется новым деплоем.

Перед заменой production проверяется отдельный кандидат: health, все десять страниц, обложки, поиск, 404 и robots. При ошибке после переключения восстанавливается предыдущий Docker-образ вместе с его базой.

Контейнер: `seo-rowna-sciana`. Адрес на VPS: `127.0.0.1:5005`. Compose и отметка коммита: `/opt/seo-sites/rowna-sciana/`. Удаление образов других сервисов и изменение их конфигурации в скриптах отсутствуют.

## Домен и индексация

Домен подключён 01.11.2026: **https://rownasciana.site/**. В Namecheap BasicDNS через браузер настроены A `@` → `65.108.142.86` (Automatic) и CNAME `www` → `rownasciana.site.` (30 min). Почтовые настройки сохранены. Конфигурация [ops/rowna-sciana.caddy](ops/rowna-sciana.caddy) установлена в `/etc/caddy/domains/rowna-sciana.caddy` и импортирована из Caddyfile. HTTPS включён автоматически; `www` перенаправляется на основной домен с сохранением пути и query string. HTTP перенаправляется на HTTPS.

Индексация открыта по запросу владельца 01.11.2026: статьи, главная и информационные страницы доступны роботам. Внутренний поиск помечен `noindex, follow`, API исключён. Sitemap: https://rownasciana.site/sitemap.xml (13 URL). Страницы имеют canonical, статьи — Article JSON-LD. Независимая техническая экспертиза и вычитка польским редактором ещё не выполнены. Обложки — подписанные AI-иллюстрации, не фотографии испытаний.

Исходные SEO-исследования скопированы в локальную папку `research/`, исключённую из Git. Исторические VALIDATION-файлы относятся к прежней Cloudflare-версии. Актуальные проверки переноса фиксируются отдельно.


## Поисковые кабинеты, аналитика и скорость

Google Search Console: доменное свойство `sc-domain:rownasciana.site`, подтверждение через публичный DNS TXT. Bing Webmaster Tools: `https://rownasciana.site/`, подтверждение через DNS CNAME. Оба проверочных DNS-записи нужно сохранять. Статусы отправки sitemap и поступления данных проверяются отдельно от подтверждения владения.

GA4: отдельное свойство **Równa ściana — rownasciana.site**, ID `561803032`, поток `16247032476`, measurement ID `G-P2CMVVZ851`. Часовой пояс Europe/Warsaw, валюта PLN. Tag загружается только после явного согласия; отказ сохраняется, выбор можно изменить внизу страницы. Google Signals и персонализация рекламы выключены в конфигурации. В настройках потока выключены site search, form interactions и video engagement. Поисковая фраза и произвольные параметры не передаются в page_location, referrer очищается от параметров. На сайте пока нет рекламы.

Публичные сведения об операторе и контакт для обращений по персональным данным ещё не предоставлены владельцем. Не публиковать частный email из регистратора и не считать текущий текст полноценной юридической проверкой.

Иллюстрации выдаются в WebP (1200/640 px), исходные PNG и тексты сохранены. Имена вариантов содержат хеш исходника, используется immutable cache. Полный набор WebP: 605772 байта вместо 24884156 байт PNG; мобильные варианты: 148152 байта. Пересоздание: `npm run images:optimize`. При изменении параметров кодирования менять также версию имени, чтобы не переиспользовать закешированный URL.

Проверка `npm run smoke` контролирует health, все десять статей, canonical, Article JSON-LD, доступность WebP, исключение поиска, robots и sitemap. Внешняя скорость зависит от сети и устройства; замеры из VPS не заменяют мобильный Lighthouse или полевые Core Web Vitals.
